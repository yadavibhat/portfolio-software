# Yadavi Bhat — Portfolio (Next.js)

    npm install
    npm run dev      # http://localhost:3000
    npm run build && npm start

- All text lives in `lib/data.ts` (projects, results, recognition, timeline, gallery).
- Page-wide animation (intro iris, scroll bar, cursor reticle, scroll reveal): `components/Effects.tsx`
- Hero (cursor-developed lettering, drifting light, timecode, counters): `components/Hero.tsx`, `components/Counter.tsx`
- Styles: `app/globals.css`. Images: `public/images`.
- Deploy: push to GitHub and import into Vercel.
